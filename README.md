# Calculator App – JavaScript DOM Project

A simple and interactive **Calculator App** built using **HTML, CSS, and JavaScript**, with a strong focus on **DOM manipulation** for handling user input and updating the UI dynamically.

This project demonstrates how JavaScript can control the structure and behavior of a web page using core **DOM concepts**.

## ✨ Features
- Basic arithmetic operations (+, −, ×, ÷)
- Clear and delete functionality
- Dynamic input and output display
- Button-based user interaction
- Clean and responsive UI
- Real-time updates using DOM manipulation

---

## 🛠️ Technologies Used
- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript (Vanilla JS)** – Logic and DOM manipulation

---

## 🧠 JavaScript DOM Concepts Used
- `document.querySelector()` and `querySelectorAll()`
- Event listeners for button clicks
- Updating elements using `innerText` / `value`
- Handling user input dynamically
- Conditional logic for calculations
